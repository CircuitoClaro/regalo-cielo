# 🌌 Galaxia Cósmica 3D • Detalle Especial Para Cielo ✨

Un universo 3D interactivo desarrollado con **Three.js**, diseñado como un detalle especial y único para Cielo. Inspirado en el estilo visual de AlexDev (@alexx.dev), combina efectos visuales de alta fidelidad, música y recuerdos flotantes estilo Polaroid.

---

## ✨ Características

- 🪐 **Agujero negro cósmico 3D:** Disco de acreción neón fucsia/rosa con efecto de lente gravitacional.
- 💖 **Espiral de partículas estelares:** Miles de estrellas y corazones flotantes animados en tiempo real.
- 📸 **Fotografías Polaroid 3D orbitando:** Fotos con dedicatorias personalizadas para Cielo que se pueden hacer clic para ampliar y leer.
- 💌 **Carta Especial para Cielo:** Botón interactivo con efecto neón que abre una carta dedicada.
- 🌠 **Estrellas fugaces:** Destellos periódicos cruzando la galaxia en el fondo.
- ✨ **Magia interactiva al hacer clic:** Burbujas con frases cósmicas y estela de polvo de estrellas al mover el cursor.
- 🎵 **Música ambiental integrada:** Reproductor de audio con ecualizador animado en el HUD superior.

---

## 🚀 Cómo abrirlo

### Opción 1: GitHub Pages (Online)
Puedes activarlo en tu repositorio yendo a **Settings > Pages > Branch: `main`** para obtener un enlace público y compartirlo directamente desde el móvil o PC.

### Opción 2: En local
1. Haz doble clic en `Abrir_Regalo.bat` o abre directamente `index.html` en cualquier navegador moderno.
2. Si tienes Node.js instalado, también puedes ejecutar `node server.js` para abrirlo en un servidor local (`http://localhost:3000`).
